# Test iniziale — Prerequisiti di prima e seconda media

Obiettivo: trovare **dove sono i buchi** prima di iniziare il programma di terza. Non è una verifica: a Karim si presenta come "mappa di partenza", senza voto.

## Regole di somministrazione
- **Durata**: una sessione da 2 ore → Parte 1 (~40 min) ; pausa 10 min ; Parte 2 (~45 min).
- **Niente calcolatrice.** Foglio e penna per i calcoli.
- **Adattivo**: in ogni area si parte dalle domande base (B). Se sbaglia **2 domande base**, l'area si chiude e diventa rossa (niente frustrazione inutile).
- **Si registrano**: risposta, tempo per domanda, tipo di errore (colonna "Errore tipico").
- **Unità di misura**: risposta giusta senza unità = mezza risposta, e l'errore va nel registro.

Livelli: **B** base ; **M** medio ; **A** avanzato

## Valutazione

### Per area
| Colore | Risultato | Significato |
|---|---|---|
| 🟢 Verde | ≥ 90% | Padroneggiato → solo ripasso distanziato |
| 🟡 Giallo | 60–89% | Fragile → consolidare in parallelo al programma di terza |
| 🔴 Rosso | < 60% o area chiusa dopo 2 errori base | Lacuna → recupero **prima** degli argomenti di terza che ne dipendono |

### Ordine di recupero (dipendenze)
Si recupera nell'ordine **A → B → C → D → E/I → F → G → H**, rispettando la mappa delle dipendenze (`math-grade8-analysis.md` §4):

| Area rossa | Blocca in terza |
|---|---|
| A, C (calcolo, frazioni) | Tutta l'algebra: relativi, monomi, equazioni |
| B (mcm) | Equazioni con denominatori |
| D (potenze, radici) | Monomi, Pitagora nei solidi |
| E, I (proporzioni, %) | Funzioni, statistica, problemi d'esame |
| F (equivalenze) | Solidi: volume, capacità, peso |
| G, H (aree, Pitagora) | Cerchio, solidi, piano cartesiano |
| K (problemi) | Tutto: si lavora ogni giorno nel blocco Problemi |

### Output per Karim
- Mappa a colori delle aree, **senza voto**.
- Messaggio motivante: "da qui partiamo", con i primi 2–3 obiettivi concreti.

### Output per l'adulto
- Mappa a colori + errori tipici rilevati + tempo medio per area.
- Piano di recupero proposto con le prime 2 settimane.
